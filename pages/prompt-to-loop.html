概念第 10 週

從 Prompt 到 Loop：寫一份會自己跑的規格

Loop 寫清目標、限制、完成標準、停止條件、觸發，寫一次跑很多輪。

老闆還是一直在盯

  1. 你交辦工作「幫我做一份簡報。」
  2. AI 做出一版看起來完成了。
  3. 你檢查發現第 5 頁字太多。
  4. 再一次這就是 loop，只是現在由你來推動它。

不要寫 prompt，寫 loop

Claude Code 負責人 Boris Cherny 說，他的工作是寫 loop。Addy Osmani 在 2026 年 6 月把這種做法命名為 loop engineering，意思是把「下 prompt 的人」換成一套流程。

最早的 loop 只有一行，是 Geoffrey Huntley 在 2025 年 7 月提出的 Ralph loop：

while :; do cat PROMPT.md | claude ; done

同一份 PROMPT.md 每一輪都重餵一次。讓它運作的不是 prompt 本身，而是重複、檢查、用檔案記進度。看起來很笨，但真的會動。

寫 prompt寫 loop
寫的內容這一輪要做什麼目標、完成標準、驗證、停止規則
下一步誰決定你讀完再寫下一句系統依檢查結果決定
寫幾次每一輪都寫寫一次，跑很多輪
你的角色黏著劑設計者、審查者

一個 loop 要寫清楚五件事

  1. 🎯 目標要什麼成品
  2. 🚧 限制哪些不能動
  3. ✅ 完成標準怎麼算做完
  4. 🛑 停止條件做不到時，何時停手
  5. ⏰ 觸發什麼時候開始跑

前三件就是上週當好老闆學過的交辦三件事。

🧮 程式檢查

測試有沒有過？連結斷了沒？每頁有沒有出處？

🧑‍⚖️ AI 審查

內容有沒有忠於來源？說法有沒有講反？

不要叫 AI 審自己的作品

AI 審查要開一個新的對話，只給它成品和來源。

Loop 也要剎車

  • 硬上限：最多改 3 輪
  • 資料不足就停：不要用自己的知識硬湊
  • 會花錢：一個 loop 用掉的 token 遠多於聊天
記住

沒人看管的 loop，就是會在沒人看管的情況下犯錯的 loop。

重點回顧

  • 寫 prompt 是每輪下指令，寫 loop 是寫一份會自己執行的規格
  • Loop 五件事：目標、限制、完成標準、停止條件、觸發
  • 完成標準分成程式檢查和 AI 審查，審查要開新對話
  • 一定要設剎車：輪數上限、資料不足就停
