Harness：AI 的工作裝備

模型負責想，Harness 負責做；決定 AI 好不好用的是 Harness。

LLM 本身只會生成文字

  • 它不會打開你的資料夾
  • 它不會建資料夾、修改檔案
  • 它不能自己上網查最新資料

那 AI 是怎麼「動手」的？答案就是 Harness。

大腦 vs 工作裝備

AI Model（大腦）

負責想：理解、規劃、判斷、生成。

Harness（工作裝備）

負責做：把模型說的「我要開這個檔案」真的執行，再把結果回報給模型。

一個完整的 Harness 有什麼？

元件作用
💻 工作環境有自己的電腦（沙盒），可以存檔、跑程式
🧰 工具讀寫檔案、終端機、瀏覽器、網路搜尋
🔌 連接器（MCP）接上 Gmail、行事曆、雲端硬碟等你的 App
📘 技能（Skills）一個資料夾＋一份 SKILL.md，教它某件事的標準作業流程
📜 規則檔CLAUDE.md / AGENTS.md，每次上工前先讀
⏰ 排程時間到了，自己開工
關鍵觀念

模型大家都差不多，決定好不好用的是 Harness。

和上個單元的差別

之前用 AISuite 手刻現在用 Agent 產品
工具自己寫 Python 函數內建讀寫檔、終端機、搜尋
規則寫在程式裡的 system promptCLAUDE.md / AGENTS.md
錯誤處理自己處理錯誤和重試產品幫你處理

重點回顧

  • LLM 只會生成文字，動手靠 Harness
  • Harness 六件套：環境、工具、連接器、技能、規則檔、排程
  • 規則檔（AGENTS.md）是我們最容易自己動手調整的部分
