AI Agent 到底是什麼？

AI Agent = AI Model + Harness，就是教 AI 用你的方法做事。

是什麼？

在 LLM 時代，AI 代理（AI Agent）說穿了就是：教 AI 用「我們做事的方法」做事情。

AI Agent = AI Model + Harness

模型是大腦，負責想；Harness 是工作裝備，負責把想法真的做出來（下一張卡細講）。

從「問 AI」到「交辦給 AI」

以「我的桌面好亂」為例：

對話式 Chat

AI 要你貼上 87 個檔名，給你分類建議。最後你自己建 5 個資料夾、一個一個拖檔案。
AI 出一張嘴，事情都你在做。

代理式 Agentic

你說「先給我看計畫」。AI 自己打開資料夾、提出分類，你說「可以，照做」，它建資料夾、搬檔案、回報結果。
你出一張嘴，AI 來完成。

對話式 Chat代理式 Agentic
你在做的事問問題交辦一件工作
AI 像是顧問員工、同事
過程一問一答，你全程在場多步驟自己做，你可以離開
能碰的東西對話框裡的文字檔案、瀏覽器、工具
你拿到的一段回答一份成品

我們走到哪了？

課程路線：Prompt Engineering → Context Engineering → Harness Engineering → Loop Engineering → Graph Engineering，也就是從 Chat Bot 走向 AI Agent。

回顧上一單元

我們用 AISuite 手刻過 Reflection、Tool Use、Planning，但還是有點麻煩，完全沒有「自己是老闆」的感覺。這週改用現成的 Agent 產品，換你當老闆。

重點回顧

  • AI Agent = AI Model + Harness
  • Agent 的本質是「教 AI 用你的方法做事」
  • 對話式拿到一段回答；代理式拿到一份成品
