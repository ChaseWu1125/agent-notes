Agent 學習卡
員工手冊GitHub

一張卡，
3 分鐘搞懂一個 AI Agent 概念

把每週的 AI Agent 課程筆記，依照同一套規則（AGENTS.md）交給 AI 整理成學習卡。目前共 0 張。

    這個網站怎麼長大？

    1. 上完課，把筆記存成 raw/週次-主題.md
    2. 對 AI 說：「請先讀 AGENTS.md，再把 raw/… 整理成學習卡」
    3. AI 依模板產生 pages/<slug>.html 並登記到 data/pages.js
    4. 首頁、分類、上一張／下一張自動更新
